# Clinexa Website

**Digital Cornerstone of Modern Healthcare Tech**

A bilingual (English/Arabic) healthcare technology website built with a minimal, systematic design philosophy.

## 🏗️ Project Structure

```
clinexa-website/
├── index.html          # Main HTML file with all sections
├── css/
│   └── styles.css      # Complete styling with RTL support
├── js/
│   └── main.js         # Interactive features & language toggle
└── images/             # Image assets directory
```

## ✨ Key Features

### Bilingual Harmony
- **Full English & Arabic Support**: Seamless language switching
- **RTL/LTR Adaptation**: Complete layout direction changes
- **Perceived Size Matching**: Balanced typography across languages
- **Language Persistence**: Saves user preference in localStorage

### Design Philosophy
- **Minimal + Systematic**: Clean, purposeful design without decoration
- **8-Column Modular Grid**: Scalable and predictable architecture
- **Color System**: 
  - Primary Text: `#0F172A` (Charcoal Slate)
  - Accent: `#0A84FF` (Vibrant Blue)
  - Dark Navy: `#020617` (for inverse mode)

### Typography
- **English**: Inter font family
- **Arabic**: IBM Plex Sans Arabic
- **Modular Scale**: Consistent sizing across all devices

### Sections Included
1. **Hero**: Focal point with data-flow network background
2. **Philosophy**: Core brand values (System, Modular, Bilingual)
3. **Solutions**: Product modules with feature lists
4. **About**: Brand identity and symbol meaning
5. **Resources**: Case studies and downloadable content
6. **Contact**: Language-sensitive contact form

### Interactive Features
- Smooth scroll navigation
- Mobile responsive menu
- Scroll-triggered animations
- Form validation (bilingual)
- Language toggle button

## 🚀 Getting Started

### Option 1: Local Server
```bash
cd clinexa-website
python3 -m http.server 8080
# Visit http://localhost:8080
```

### Option 2: Open Directly
Simply open `index.html` in any modern web browser.

## 📱 Responsive Design

The website is fully responsive with breakpoints at:
- **Mobile**: < 768px
- **Tablet**: ≥ 768px
- **Desktop**: ≥ 1024px

## ♿ Accessibility

- Semantic HTML structure
- ARIA labels on interactive elements
- Focus states for keyboard navigation
- Reduced motion support
- High contrast color scheme
